# Hello World — repositorio de pruebas

Página estática con HTML y CSS para probar un flujo de trabajo con VS Code, Git y commits asistidos por IA.
Incluye un botón para alternar entre el tema original y uno alternativo.

## Uso

Abre `index.html` en un navegador. No necesita instalación ni dependencias.

## Ideas para ensayar commits

1. Cambiar el texto de `h1` en `index.html`.
2. Modificar `--accent` en `css/styles.css`.
3. Añadir una sección a la tarjeta.
4. Cambiar la etiqueta de versión a `V1.1`.

Los cambios deben guardarse antes de generar el resumen de la sesión.
